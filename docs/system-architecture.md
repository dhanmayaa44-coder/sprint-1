# Gym Management System – System Architecture

The Gym Management System follows the MERN Stack architecture.

## Frontend
React.js is used to create the user interface and manage application state.

## Backend
Node.js and Express.js are used to create REST APIs and handle application logic.

## Database
MongoDB is used to store users, members, trainers, membership plans, attendance, and payment records.

## Architecture Flow

React.js
↓
Express.js / Node.js
↓
MongoDB
